# Security Policy / Güvenlik Politikası

## Türkçe

Bir güvenlik açığını herkese açık issue olarak paylaşmayın. GitHub profilindeki iletişim kanalı üzerinden **tv3m / @iflaholmaz** ile özel olarak iletişime geçin. Raporunuza etkilenen sürümü, tekrar adımlarını ve olası etkisini ekleyin.

Yalnız son yayın desteklenir. Güvenlik uyarısı nedeniyle Defender'ı kapatmanız veya dosyayı istisnalara eklemeniz istenmez.

## English

Do not disclose a vulnerability in a public issue. Contact **tv3m / @iflaholmaz** privately through the contact channel on the GitHub profile. Include the affected version, reproduction steps, and potential impact.

Only the latest release is supported. Users are never asked to disable Defender or add the project to exclusions because of a security warning.
